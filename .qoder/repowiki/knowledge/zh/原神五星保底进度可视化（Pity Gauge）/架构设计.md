采用典型的 Vite + React 单页架构：`src/main.jsx` 通过 `ReactDOM.createRoot` 挂载根组件 `App.jsx`；`App.jsx` 作为页面容器，负责加载配置、维护活跃用户状态并在左右滑动的杯形面板中渲染进度；业务逻辑集中在 `src/lib/pity.js`，导出 `calcPercent`、`loadProfiles`、`parseProfiles` 以及常量 `PITY_COST=14400`、`FATE_COST=160`、`BOOST_THRESHOLD=82`，实现与 UI 解耦的纯函数计算；UI 子组件 `MeasuringCup.jsx` 和 `UserSwitch.jsx` 分别负责进度条视觉呈现和用户切换交互。运行时数据来自 `public/config.properties`，由 `loadProfiles` 通过 `fetch(import.meta.env.BASE_URL + 'config.properties')` 拉取，解析失败时回退到内置 `FALLBACK_PROFILES`。构建产物输出至 `dist/`，由 `.github/workflows/deploy-pages.yml` 在 push main 分支时通过 GitHub Actions 构建并部署到 GitHub Pages，同时包含 SHA 新鲜度校验以避免陈旧制品发布。字体资源与图片静态托管于 `public/fonts/` 与 `public/image/`。
